## 처음 제안한 운반 팩을 바꾼 이유

[Crafting Mecanim Animation Pack FREE](https://assetstore.unity.com/packages/3d/animations/crafting-mecanim-animation-pack-free-45047)는 Carry Pickup, Carry Idle, Carry Putdown, Carry WalkForward 등을 무료로 제공한다. 다만 이 동작은 몸 가까이 물체를 드는 운반용이므로 기획서의 3m 중력 잡기에 그대로 맞지 않는다. 필수 추천에서 빼고 Spellcasting의 시작·유지·종료를 장갑 표현 후보로 검토한다.

무료라고 확인한 것과 기획서에 전용 동작으로 완벽하게 맞는 것은 다르다. 전문 제작된 레버·구조·돌진 세트를 확보했다고 표현하지 않는다. 기존 동작 재사용과 소규모 보정도 사용자 검수 대상으로 남긴다.

## 도입 후 검수 순서

1. 무료 패키지의 실제 클립·버전·라이선스 문구를 기록한다. 모델과 예제 컨트롤러를 자동으로 게임에 연결하지 않는다.
2. Synty 캐릭터 한 명에 Humanoid Avatar를 확인하고 이동·점프·공격·잡기 대표 동작부터 연결한다.
3. Rigidbody 이동과 루트 이동이 겹치지 않는지, 발·손·무기 접촉과 비율이 맞는지 본다.
4. 기본 레이어와 장갑 상체 레이어를 섞고 공격·피격·다운에서 장갑 레이어가 해제되는지 본다.
5. 잡은 채 이동, 잡기 중 피격, 공격 중 다운, 돌진 충돌 후 복귀, 구조 취소·완료를 각각 짧게 촬영해 검수받는다.
6. 무료 팩으로 맞지 않는 부분이 있으면 먼저 보정 작업량을 제시한다. 유료 에셋으로 자동 변경하지 않는다.
