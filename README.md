# SoloProject

Unity 기반 2인 온라인 협동 물리 액션 퍼즐 개인 프로젝트입니다. 기획과 메인 프로젝트 에셋 임포트를 마쳤으며, 게임 기능은 구현 전입니다.

중력 장갑으로 물체를 옮기고 장치를 작동시키며 적을 상대하는 짧은 협동 플레이를 목표로 합니다. 공고의 물리 퍼즐, 전투와 AI, NetCode, 콘텐츠 제작 도구, Animator, Addressables, 그래픽스 항목을 개발 및 검증 대상으로 다룹니다.

- Unity 버전: `6000.6.0f1`
- 렌더 파이프라인: URP
- 기본 브랜치: `main`
- 기획 문서: [중력정비반 개인 프로젝트 기획서](Docs/중력정비반_개인프로젝트_기획서.md)

범위는 방 2개, 퍼즐 장치 2종, 적 2종이며 퍼즐·웨이브 도구는 한 편집 창으로 묶습니다. 기획서는 기능별 작업량과 성능·네트워크·애니메이션 검증 기준을 포함합니다. 초기 작업량은 수정 여유를 포함해 264~399시간이며, 기술 실험 후 다시 산정합니다.

외형은 Synty 로우폴리 A안을 기준으로 검토 중입니다. 애니메이션 실제 파일을 확보하고 별도 URP 프로젝트에서 Sidekick Starter_03에 17개 동작 후보와 상체 마스크 혼합 포즈를 확인했습니다. 전용 셰이더 의존성도 보완했습니다. 최종 사용자 시각 승인과 제품 Animator·접촉·온라인 검수는 남아 있습니다. 실제 실무 연차와 콘솔 개발 경험은 프로젝트 기능과 구분해 기록합니다.

외부 아트와 애니메이션 원본은 공개 저장소에 포함하지 않습니다. [에셋과 애니메이션 검수안](Docs/에셋_애니메이션_검수안.md)에 출처와 확인 상태를 기록하고, 검수 이미지와 실제 클립 메타데이터도 확인할 수 있습니다.

필요한 무료 5팩과 Quaternius 보완 모션은 메인 `Assets/ThirdPartyArt` 아래에 제작자별로 정리했습니다. 메인 Unity에서 클립 레코드 313개와 Humanoid 후보 10개를 확인했습니다. 실제 경로·설치 범위·검증 결과는 [에셋 설치 및 폴더 구조](Docs/에셋_설치_및_폴더_구조.md)에 기록했습니다.

Unity Hub에서 이 폴더를 프로젝트로 열어 지정 버전의 에디터로 실행합니다. `Library`, `Temp`, 개인 설정, 문서 검수용 렌더와 백업은 버전 관리에서 제외합니다.
